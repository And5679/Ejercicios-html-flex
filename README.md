# Taller Práctico Integrador - Vectores y Algoritmos de Búsqueda/Ordenamiento

## 📖 Descripción
Este proyecto corresponde al *Taller Práctico Integrador (página 7)* de la asignatura  
*Vectores y Algoritmos de Búsqueda/Ordenamiento*.  

El objetivo es *implementar y comparar diferentes algoritmos de ordenamiento y búsqueda*, midiendo su rendimiento en diferentes tamaños y distribuciones de datos.

---

## 📦 Requisitos
- Python 3.8 o superior  
- Librerías necesarias:
  - numpy
  - pandas
  - matplotlib
